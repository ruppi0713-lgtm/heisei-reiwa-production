# templates

使い回す制作テンプレの置き場です。1回作れば、話数ごとに使い回します。

## これから入れるもの（優先順）

1. Motion Canvas：数字カウンター（カウントアップ式、表記固定）と図解パートのテンプレ
2. Flubber：「平成の物 → 令和の物」の変形トランジション（ガラケー→スマホ等、シルエット絵同士）
3. Remotion：テロップ・SE・カウンター合成とMP4書き出しの土台プロジェクト
4. tsParticles：紙吹雪・雪・桜などの粒子の設定
5. Rough.js：手描き風の矢印・丸・注釈のパーツ

## 置き方

- テンプレごとにフォルダを切り、使い方をそのフォルダのREADMEに書く。
- 出典：2026-11-23のXポスト（@okapi_fukugyo「Museでモーションデザイン11選」）。一覧とライセンス注意は design-reference リポジトリの `2026-11-23_okapi_Museでモーションデザイン11選.md`。
- LYGIA は非商用のみ無料のため、テンプレに入れない。
