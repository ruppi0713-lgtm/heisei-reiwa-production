# デザイントーン改修パック（色・トーン＆マナーを明るくパキッと）

目的：映像全体のデザイン性・カラーリング・トーン＆マナーをそろえて、「薄くて合ってない」状態から「明るく、パキパキした」状態にする。
モデル磨き上げ（`scripts/model_smooth_pack.md`）とセットの改修で、テスト成果物も合体で出す。

## 直す所（Codexへの指示）

```
色
- 平成＝オレンジ、令和＝ブルーを、彩度を上げた原色寄りで固定する
  （パステル・くすみ色に寄せない）
- 背景はキャラが沈まない明るさとコントラストにする
  （背景が淡い＋キャラも淡い、の重なりを禁止）
- 差し色は話数ごとに変えず、アカウント共通で固定する

明るさ・質感
- 照明を全体に明るくし、影は柔らかく浅くする
- 色の「薄さ」の原因（彩度不足・光の当て方・背景との同化）を先に特定してから直す

トーン＆マナー（全話で統一）
- テロップの書体・太さ・縁取り・色使いを1つの型に固定する
- 背景の描き方（小物の量、色数）を話数ごとに変えない
- 画面の余白と要素の置き方をそろえる
- 迷ったら design-reference リポジトリの「AI味を消すデザイン」ノートに寄せる
```

## 成果物（モデル磨き上げと合体テスト）

```
1. 比較用の静止画（前／後）：モデル磨き上げと同じ3カット
   （正面・横向き・顔アップ）で、色とトーンまで適用した版
2. テスト動画：5秒程度（歩き＋ひと言の掛け合い）、新トーン適用
3. 色の固定表：平成色・令和色・背景色・差し色の指定を1枚にまとめる
4. 記録を outputs/ に置く
```

## 合格の条件（山下達郎チェック）

- 画面全体が明るく、色がパキッと分かれて見える
- キャラと背景が同化していない
- テロップ・背景・小物のトーンが ep01〜04 の良い所と地続きで、
  別アカウントに見えない
- 「AIで作った安っぽさ」がない（Impeccableの考え方で仕上げ確認）

合格したら、この色とトーンを今後の全話の固定にする。
