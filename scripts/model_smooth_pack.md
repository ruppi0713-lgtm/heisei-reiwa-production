# モデル磨き上げパック（3Dキャラを滑らか・シームレスに）

目的：平成さん・令和さんの3Dモデルを、カクカク感のない滑らかでつなぎ目のない質感にする。
実写化ではない。キャラの形・色・小道具・頭身は今のまま変えない。「表面の滑らかさ」だけを上げる一度きりの改修で、終わったら全話共通の固定モデルにする。

## Codexへの手順（Blender、PC側）

```
0. 今のモデルファイルを別名でバックアップしてから始める
1. 全キャラメッシュに Shade Smooth を適用
   （Blender 4.1以降は「角度でスムーズシェード」も併用）
2. 頭・体のメッシュに Subdivision Surface（レベル2）を追加
   - 輪郭が痩せすぎる所はクリースで保つ
   - アホ毛・髪のシルエットは今の形のまま
3. WeightedNormal でハイライトの流れを整える
4. 関節まわり（首・肩・肘）のつなぎ目と凹みをチェックして直す
5. マテリアルは今の色のまま（平成＝オレンジ、令和＝ブルー、濃くはっきり）
   質感だけ均一にそろえる。色・柄は変えない
6. 小道具（ガラケー・スマホ・イヤホン）は角をほんの少しだけ丸める
   （Bevel少量）。形と色は変えない
```

## 成果物（チェック用に先にこれだけ出す）

```
1. 比較用の静止画（前／後）：正面・横向き・顔アップ の3枚ずつ
2. テスト動画：5秒程度（歩き＋ひと言の掛け合い）
3. 保存先：characters_v2.blend（新しい固定モデル）
4. 記録を outputs/ に置く（何を変えたか、レンダリング時間の変化）
```

## 合格の条件（山下達郎チェック）

- シルエット・頭身・髪型・色・小道具が前と一致している
- 顔と体に変な凹み・つなぎ目がない
- 動きで関節が破綻しない
- レンダリング時間が極端に増えていない（増えた場合は記録に明記）

合格したら characters_v2.blend を今後の全話の固定モデルにする。
不合格なら、バックアップから戻して、直す所だけ指示を足す。
