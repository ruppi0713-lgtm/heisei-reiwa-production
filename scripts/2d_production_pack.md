# 2Dイラスト版 制作パック

3D版と並ぶ、新しい絵柄のテスト制作。2026-11-24に「たまごっち」回でテスト版を1本作り、ちあき確認済みの仕様をここに固定する。2D版を作る時は、このパックが正本（AGENTS.mdのテロップ色ルールより、こちらのテロップ仕様を優先）。

## 絵柄

- 私立パラの丸高校系の2Dイラストアニメ
- 平成初期（90年代前半）のテレビアニメの質感：セル画っぽい平たい塗り、少しの粒状感、少し色あせた温かみのあるカラーリング
- 背景はシンプルに。キャラと小物が主役

## キャラ（人間版・テスト確認済み）

- 平成さん（女性）：オレンジ髪のボブ＋アンテナ状のアホ毛／オレンジのダボッとしたパーカー／腰にチェックシャツ／ストラップ付きガラケー／明るく感情ゆたか、動き大きめ／少し小柄
- 令和さん（男性）：青〜ミント系／短髪／ワイヤレスイヤホン／スマホのみ／クールで淡々、動き小さめ／少し背高め
- どちらも相手をバカにしない。最後は2人並んで終わる

※別案として動物ゆるキャラ版（平成＝オレンジの丸い猫／令和＝水色の丸いペンギン、背景なし・シンプル）の検討も進んでいる。**どちらのキャラで作るかは、着手前に必ずちあきに確認すること。**

## 制作方法

- 最初にキャラシート（正面・横・表情差分）を固定し、全カットでその絵を使う。カットごとに絵を生成し直さない（顔がブレる）
- 動きは小さく：体の上下の揺れ、まばたき、口の開閉、小物の小さい動き
- 1080×1920、22〜30秒
- 0秒フック＝問いテロップ＋「平成の物のアップ」か「顔アップ」の強い方＋1行目テロップ同時出し

## テロップ仕様（確定・最重要）

- フォントは**ウェイト900のBlack**（Noto Sans CJK Black、M PLUS 1p Black等）。太さはフォント自体のウェイトで出す。縁取りを太くして太く見せるのは禁止
- 見出し（問い）と締めの問い：**不透明の黒板を1枚だけ**敷く
  - 半透明の帯を重ねるのは禁止。重なった部分だけ濃くなり、境目が見えて違和感になる
  - 半透明で下の絵を透かすのも禁止。絵の明暗が透けて濃さの段差に見える
- セリフ：**帯なし**。白文字＋細い黒フチ＋影で読ませる
  - 早めに改行して左右に余白を残す。画面幅いっぱいに広げない（端で切れる）
  - 位置とサイズは全カット完全固定。カットごとに動かさない
- テキストの切り替え：**次のテキストが来るまで、前のテキストを残す**。テキストが消える瞬間を作らない（チカチカする）
- 話者の区別：セリフの上に小さい色札（平成＝オレンジ地／令和＝ブルー地、白文字で名前）
  - セリフ本文の色は**白で統一**。色文字は服や髪の色と重なって読めなくなるため禁止
- カウンター等の数字表示も白文字＋フチ、位置は固定

## 音声

- VOICEVOX：平成さん＝春日部つむぎ／令和さん＝青山龍星、速度1.1倍（変更禁止）
- セリフはテロップの表示枠に収まる長さで台本を作る。収まらない時は台本を短くする

## BGM

- **必須**。無音だと間延びする
- 薄いが確実に聞こえる音量で、全編途切れず流す（持続音＋小さなメロディのループ等）
- バランスの基準：声を少し下げ、BGMを少し上げる。セリフのない区間でもBGMだけが自然に聞こえる量にする

## サンプル台本（テスト制作済み・たまごっち回／ネタ帳No.27）

```
見出し（全編固定）：たまごっち、／授業中も世話してた？
カット1 平成：授業中もポケットで／世話してたの（たまごっちの寄り）
カット2 平成：音は消して。／うんち出たら授業どころ／じゃないの！（カウンター「お世話 12回」）
カット3 令和：今はアプリが／通知してくれます。／お世話もタップ1つです
　　　→ 逆転 令和：通知、消したまま／忘れてました
カット4 平成：死なせちゃった時の／気持ち、今も覚えてる
締めの問い：たまごっち、死なせたことある？
```

## 検品チェックリスト

- □ キャラの顔・髪型・服が全カット同じ
- □ 見出しと締めの板が1枚・不透明で、境目や段差がない
- □ セリフが画面の端で切れていない、左右に余白がある
- □ テキストが消える瞬間がない
- □ 声とテロップのタイミングが合っている
- □ BGMが全編聞こえる（セリフのない所でも）
- □ 締めの問いで終わっている
