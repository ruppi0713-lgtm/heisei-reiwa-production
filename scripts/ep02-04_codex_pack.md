# ep02〜ep04 Codex指示書パック（平成さんと令和さん）

前提の準備（毎回やる合図）:
1. Blenderを開いて、Nパネルの「MCP for Blender」が「Connected on localhost:9876」になっていることを確認
2. Codexを再起動して、新規チャットで始める
3. VOICEVOXを起動しておく
4. キャラ・舞台のモデルはep01のプロジェクトを流用する（作り直さない）

声の指定（確定）:
- 平成さん: VOICEVOX「春日部つむぎ」
- 令和さん: VOICEVOX「青山龍星」
- 速度1.1倍。書き出し後に各行の長さを確認する

## 共通仕様（ep01の確定版＋反省の反映。全話共通）

映像:
- 縦動画 1080×1920、尺は22〜30秒
- 0秒フック: 問いテロップ＋「平成の物のアップ」か「顔アップ」の強い方＋1行目テロップを同時出し。前置き・間はなし。条件: ①その画だけで何の話か分かる ②動きがある ③キャラの顔は3秒以内に出す
- 対比は画面で見せる: 平成の物・行動と令和の物・行動を同じ構図で切り替える。具体物のアップ（寄りの画）を各話1回は入れる
- 中盤（12〜15秒）に立場の逆転を1回。オチは反転ブーメラン→即カット（挨拶・予告なし）
- 背景は明るめに（ep01は暗かった）
- スマホ画面の中身は「言葉」で表示する（数字だけだと時刻に見える）

テロップ（Remotion）:
- 上部の問い: 2行・88px・太字・半透明の黒帯の上。平成＝オレンジ／令和＝青／それ以外は白。全編固定表示
- セリフ: 76px・太字・白の太縁取り＋半透明の黒帯、上から28%の位置に全シーン固定。平成＝オレンジ／令和＝青。1行13〜18字に収まるよう改行
- フォントは Noto Sans JP Bold
- 進捗UI（カウンター等）: 左側、下から450pxの位置。数字は規則正しく増やす（飛ばさない）
- 締めの問いテロップ: 最終フレームに必ず表示。下から450pxの位置（ep01で欠落したので最重要チェック項目）
- SEは場面の切り替わりと逆転ポイントだけ。BGMはなし

進め方（1話ごと）:
- ステップA: VOICEVOXで音声書き出し（line01.wav〜、各行の長さを報告）
- ステップB: Blenderで無音の映像（音声の長さに尺を合わせる）
- ステップC: Remotionで合成してmp4書き出し
- 完成したmp4はチェックに出す
